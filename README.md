# Pulkovo Flex Test Task

Адаптивная верстка тестового задания для страницы вакансий Pulkovo Flex.

## Что реализовано

- список вакансий;
- детальная страница вакансии;
- модальное окно отклика;
- страница профиля пользователя;
- адаптация под десктопные и мобильные экраны.

## Как открыть

Проект не требует сборки и запуска backend. Достаточно открыть файл:

```text
index.html
```

Также можно запустить локальный сервер из папки проекта:

```bash
python3 -m http.server 5173
```

После этого сайт будет доступен по адресу:

```text
http://127.0.0.1:5173/
```

## Примечание

Так как в рамках тестового задания нет доступа к базе данных и backend-авторизации, профиль заполнен тестовыми данными. Интерфейс изначально отображается в состоянии авторизованного пользователя.
